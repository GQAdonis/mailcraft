- **A model that is always there, and gateways said for what they are.** When your chosen model server can't answer, or you set none up, Apple's on-device model can answer instead, once you've confirmed it in File › Options › AI assistance; the answer says which model gave it. A gateway on this computer that sends your mail to the internet (such as LiteLLM) is now a kind of its own and asks your yes for each account, and a server set up as "on this computer" is checked for being one. File › Options › AI assistance has a primary and a backup, Test Connection with a model picker, and the context window. See [docs/ai.md](docs/ai.md).
